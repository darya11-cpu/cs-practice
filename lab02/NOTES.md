# Рабочая папка - это папка на локальном компьютере, где напрямую происходит работа с файлами проекта: редактируется, удаляется. Здесь вносятся изменения, но они пока не зафиксированы в истории проекта.

# Индекс - это промежуточное хранилище, буфер между рабочей папкой и репозиторием.

# Коммит - это фиксация изменений в истории проекта.

# Git - Работа с ним происходит на локальном компьютере.

# GitHub - центральный репозиторий, с которым синхронизируются локальные копии.

# git diff - показывает незастэйженные изменения - то, что изменено в файлах, но ещё не добавлено в индекс командой git add.

# git diff --staged - показывает разницу между подготовленными изменениями (теми, что уже добавлены в индекс) и последним коммитом.
