# git diff - показывает, какие изменения были сделаны, но ещё не добавлены в индекс и, соответственно, не попадут в следующий коммит.

# git show - выводит детали конкретного коммита.

# git log отображает историю коммитов.

# git log -S - ищет коммиты, в которых изменилось количество вхождений указанной строки в файл, то есть команда находит случаи, когда строка была добавлена или удалена.

# git blame - показывает историю строк в конкретном файле. Для каждой строки она выводит информацию о последнем коммите, который её коснулся: имя автора и хеш коммита.

# git restore - берёт версию файла из индекса. Команда отменяет все локальные правки в рабочем каталоге: файл возвращается к последнему сохранённому состоянию. 

# git restore --source - позволяет взять версию файла из любого коммита, ветки или тега в истории. Команда просто копирует нужную версию в рабочее дерево и/или индекс.

# git revert - добавляет новый коммит, который отменяет изменения указанного. Исходный коммит остаётся в истории.

# git resert --hard - переписывает историю, удаляя указанный коммит из ветки.

# Использование git revert в опубликованной истории безопаснее по нескольким ключевым причинам. Исходный коммит остаётся в истории, а поверх него добавляется новый коммит-откат. Все участники команды видят, какие решения были отменены и когда.
